# Lessons

- When a user retracts a document category, remove its artifacts and every active reference instead of renaming it.
- When a user changes the task-record format, migrate historical records and every active instruction to the requested report path and naming convention.
- When relocating a guidance document, move it to the requested category and update every active path reference.
- When a template defines a document structure, reference that template from `AGENTS.md` instead of duplicating its format.
- When instructions govern a lesson record, route to LESSON-TEMPLATE.md instead of restating its format in AGENTS.md.
- When the project no longer wants agent-environment routing in AGENTS.md, remove the entire Skill Routing section rather than leaving partial directives.
- When AGENTS.md accumulates conditional tool guidance, move recommendations to README.md and retain only universal repository rules.
- When a living design guide can evolve during development, state its update rule beside its AGENTS.md pointer.
- When AGENTS.md duplicates a detailed procedure, retain only a scoped pointer to the procedure's source document.
- When documenting an AI pipeline, show the decision flow after AGENTS.md is read rather than the installation flow.
- When defining branch names, make ticket prefixes optional unless the project requires a ticket for every change.
- When maintaining `.agent-knowledge`, write all instructions, templates, examples, and placeholders in professional English; scan the full directory for other-language remnants before completing the change.
